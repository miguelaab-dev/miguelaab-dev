## Featured project

### [commodity-var-engine](https://github.com/miguelaab-dev/commodity-var-engine)

A VaR and Expected Shortfall engine for commodities, built to understand risk models end to end rather than call a library.

- Five VaR/ES estimation methods
- Three volatility models
- Walk-forward backtesting with the Basel Traffic Light framework
- Handling of the WTI crude return on April 20, 2020, when prices went negative and broke the usual log-return assumptions
